# Higher or Lower Card Game

Java console card game in which the player predicts whether the next randomly generated card will be higher or lower than the current one.

## Features
- Random card values and suits.
- Input validation for player choices.
- Five-round game cycles with continue/statistics/quit options.
- Persistent score and total-round tracking during a session.
- Player levels based on accumulated points.
- English, Irish, and German interface messages.
- ANSI colours and text formatting for console feedback.

## What I practised
Java control flow, loops, methods, randomisation, user input, validation, application state, basic localisation, console UI, and decomposing program logic into reusable methods.
